Deeper Watchdog для Windows без Docker (portable)
=================================================

Ничего устанавливать не нужно: Python уже внутри папки.

1. Распакуйте архив в любую папку (например, C:\DeeperWatchdog).
2. Запустите Start.bat. При первом запуске он спросит:
   - IP-адрес Deeper Connect (обычно 34.34.34.34) и пароль администратора Deeper — сразу проверит вход;
   - порт веб-интерфейса (8787) и пароль для входа в веб-интерфейс (можно задать потом в браузере).
   Затем откроется браузер с веб-интерфейсом. Watchdog работает, пока открыто окно.
3. Чтобы Watchdog работал в фоне и запускался при входе в Windows: Autostart.bat
   (повторный запуск выключает автозапуск). Журнал: data\watchdog.log
4. Stop.bat — остановить фоновый Watchdog. Settings.bat — сменить адрес и пароли.

С телефона и других устройств: http://<IP этого компьютера>:8787/
(при первом запуске Windows спросит разрешение для Python в брандмауэре — разрешите для частных сетей).
Компьютер должен быть включён: для круглосуточной работы лучше Docker на NAS/роутере/сервере.

Настройки и журнал хранятся в папке data и в файле .env рядом с программой.
Обновление: замените deeper_watchdog.py новым из свежего архива (папку data и .env не трогайте).
